# Triage labels

Use the tracker label for the requested role in the ticket's `Status:` line.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting triage |
| `needs-info` | `needs-info` | Awaiting more information |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires a human |
| `wontfix` | `wontfix` | Closed without action |
