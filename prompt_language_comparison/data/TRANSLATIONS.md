# HumanEval 题面翻译

本目录的 `zh_descriptions.json` 包含 164 道题的中文说明。每个题号下面的键为官方英文题面中的行号，从 1 开始。程序只替换目标函数文档字符串中的说明，沿用官方英文题面的函数签名、导入、已有辅助代码和题面示例。示例代码、结果和主要示例块保持英文原文。原文与判分数据均按题号关联到固定版本的两套归档。

记录的问题按题号和行号修正。审校时，对照模型实际收到的两种请求，重点核对输入、返回值、边界条件、约束和字面量。例如遇到题面与给定示例的表述有出入时，应记录原题歧义并维持两版的信息一致。程序验证了全部题号的覆盖、请求的结构以及给定示例的保留。本轮已按确认的审校方式独立复核全部题目，见[审校记录](TRANSLATION_REVIEW.md)。
